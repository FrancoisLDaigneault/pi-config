# Politique de sécurité

## Versions prises en charge

Seule la dernière version publiée (branche `main`) est prise en charge.

## Signaler une vulnérabilité

N'ouvrez pas d'issue publique. Utilisez le signalement privé de GitHub :
onglet **Security** → **Report a vulnerability**
([GitHub Security Advisories](https://github.com/FrancoisLDaigneault/pi-config/security/advisories/new)).

Vous recevrez une première réponse sous 7 jours ouvrables.
